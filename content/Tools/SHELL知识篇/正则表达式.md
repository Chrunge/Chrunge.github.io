
###  正则表达式速查表 (Regex Cheat Sheet)

#### 1. 字符匹配 (匹配什么)

| 符号 | 含义 | 举例 | 匹配结果 |
| :--- | :--- | :--- | :--- |
| **`.`** | **任意单个字符**<br>(不含换行) | `g..gle` | `google`, `gOgle`, `g12gle` |
| **`[]`** | **字符集合**<br>(中括号内任选一个) | `[Ss]et` | `Set`, `set` |
| **`[^]`**| **反向集合**<br>(排除中括号内的字符) | `[^a-z]` | 匹配**非**小写字母的字符 (如数字、大写) |
| **`[a-z]`**| 范围匹配 | `[0-9]`<br>`[a-zA-Z]` | 0到9的数字<br>所有字母 |
| **`\`** | **转义符**<br>(把特殊符号变回普通字符) | `\.`<br>`\*` | 匹配点 `.` 本身<br>匹配星号 `*` 本身 |

#### 2. 位置锚定 (在哪匹配)

这是处理配置文件最常用的语法。

| 符号 | 含义 | 运维实战场景 |
| :--- | :--- | :--- |
| **`^`** | **行首** | `^#` : 匹配以 # 开头的行 (注释行) |
| **`$`** | **行尾** | `error$` : 匹配以 error 结尾的行 |
| **`^$`** | **空行** | `grep -v "^$"` : **删除文件里的空行** (必背) |
| **`\<`** | 单词首 | `\<root` : 匹配 `root` 或 `root123`，但不匹配 `chroot` |
| **`\>`** | 单词尾 | `root\>` : 匹配 `root` 或 `chroot`，但不匹配 `root123` |

#### 3. 次数限定 (匹配多少次)

**注意**：在默认 `grep` 中，`+` `?` `{}` 需要加 `\` 转义，或者直接加 **`-E`** 使用扩展正则。

| 符号 | 含义 | 举例 | 匹配结果 |
| :--- | :--- | :--- | :--- |
| **`*`** | **0 次或多次** | `ab*c` | `ac`, `abc`, `abbbc` |
| **`+`** | **1 次或多次** | `ab+c` | `abc`, `abbbc` (不匹配 `ac`) |
| **`?`** | **0 次或 1 次** | `https?` | `http`, `https` |
| **`{n}`** | 恰好 n 次 | `[0-9]{3}` | 匹配 3 位数字 (如 `666`) |
| **`{n,m}`**| n 到 m 次 | `[0-9]{1,3}` | 匹配 1到3 位数字 (IP段必用) |

#### 4. 逻辑与分组

| 符号 | 含义 | 举例 |
| :--- | :--- | :--- |
| **`|`** | **或 (OR)** | `error|warn|fail` (匹配其中任意一个词) |
| **`()`** | **分组** | `g(oo|la)gle` (匹配 `google` 或 `glagle`) |

### 💡 运维实战：常用正则组合 (直接背诵)

下面这些正则在 `grep -E` 或 `awk` 中可直接使用：

#### 1. 匹配 IP 地址 (最经典)
> 逻辑：数字.数字.数字.数字 (这里简化版，不校验 255 限制)
```regex
[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}
```
*   **命令实战**：从日志里把 IP 抠出来
    `grep -o -E "([0-9]{1,3}\.){3}[0-9]{1,3}" access.log`

#### 2. 匹配 邮箱地址
> 逻辑：字母数字@字母数字.com
```regex
[a-zA-Z0-9_]+@[a-zA-Z0-9]+\.[a-zA-Z]+
```

#### 3. 过滤配置文件 (去除注释和空行)
> 逻辑：行首不是 # **并且** 行首不是空格加 # **并且** 不是空行
```bash
# 这种写法很累：
grep -v "^#" nginx.conf | grep -v "^$"

# 正则写法 (推荐):
# ^\s*#  --> 匹配行首可能有空格(\s*)，然后是# (注释行)
# ^$     --> 空行
grep -E -v "^$|^\s*#" nginx.conf
```

#### 4. 匹配 身份证号 (18位)
> 逻辑：前17位是数字，最后一位是数字或X
```regex
[0-9]{17}[0-9X]
```

#### 5. 匹配 日期时间 (YYYY-MM-DD HH:MM:SS)
> 逻辑：4数-2数-2数 空格 2数:2数:2数
```regex
[0-9]{4}-[0-9]{2}-[0-9]{2} [0-9]{2}:[0-9]{2}:[0-9]{2}
```

### ⚠️ 正则的“坑”与避坑指南

#### 1. 通配符 `*` vs 正则 `*` (新手最容易混淆)
*   **Shell 里的 `*` (通配符)**：代表“任意文件”。
    *   `rm *.txt` -> 删除所有 txt 文件。
*   **Regex 里的 `*` (量词)**：代表“前面的字符重复0次或多次”。
    *   `grep "a*" file` -> 并不是找所有以 a 开头的行，而是找“包含0个或多个a”的行（实际上这会匹配每一行，因为空字符串也算0次）。
*   **Regex 里的“任意字符”**：是 **`.*`** (点星)。
    *   `grep "r.*t" file` -> 找 r 开头，t 结尾，中间随便什么东西。

#### 2. 什么时候加 `\` ？
*   在 `grep` (基础正则) 中：
    *   想用 `+`, `?`, `|`, `(`, `)` 这些高级功能，**必须加** `\`。例如：`grep "a\+b"`。
*   在 `grep -E` (扩展正则) 或 `awk` 中：
    *   **不用加** `\`。直接 `grep -E "a+b"`。
    *   但如果你想匹配符号本身（比如问号 `?`），则必须加 `\`。例如：`grep -E "who are you\?"`。

#### 3. 贪婪匹配问题
*   正则默认是**贪婪**的（尽可能多匹配）。
*   文本：`abc 123 def 456`
*   正则：`a.*f`
*   匹配结果：`abc 123 def` (它不会停在 c，而是一口气吃到 f)。

### 总结：运维各工具对正则的支持

| 工具 | 默认正则类型 | 建议 |
| :--- | :--- | :--- |
| **grep** | 基础正则 (BRE) | 简单的查找直接用。<br>复杂的建议加 **`-E`**。 |
| **egrep**| 扩展正则 (ERE) | 等同于 `grep -E` (推荐)。 |
| **sed** | 基础正则 (BRE) | 想用扩展正则需加 **`-r`** (Linux) 或 **`-E`** (Mac)。 |
| **awk** | 扩展正则 (ERE) | **天生支持**，写起来最爽。 |
