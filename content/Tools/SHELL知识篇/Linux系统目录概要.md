### 二、Linux 系统核心目录速查表 

#### 1. 核心配置区 (绝对的禁区与高频区)

这里是系统的“大脑”，改错了系统直接瘫痪。

| 目录 | 重点文件/子目录 | 运维实战说明 |
| :--- | :--- | :--- |
| **/etc** | **全局配置文件中心** | **(所有配置都在这)** 备份系统时首选备份它。 |
| | `/etc/sysconfig/network-scripts/` | **网卡配置** (CentOS)，配 IP 就在这。 |
| | `/etc/fstab` | **磁盘挂载表**。配错了重启就进不去系统 (Rescue模式见)。 |
| | `/etc/hosts` | **本地域名解析**。测试环境常用它强行指定域名 IP。 |
| | `/etc/passwd` & `/etc/shadow` | 用户列表(passwd) 和 **密码哈希(shadow)**。 |
| | `/etc/systemd/system/` | **服务启动配置**。手动写 `systemctl` 脚本的地方。 |
| | `/etc/sudoers` | **Sudo 权限表**。不要直接 vim，请用 `visudo` 编辑。 |
| | `/etc/resolv.conf` | **DNS 配置**。上不了网先看这。 |
| **/boot**| **启动引导目录** | 存放内核 (`vmlinuz`) 和引导程序 (`grub2`)。<br>**⚠ 警告**：如果系统起不来，或者内核升级失败，通常是这里满了。 |

#### 2. 数据与应用区 (日常操作最频繁)

这里是你的“工作台”，大部分应用部署、日志查看都在这里。

| 目录 | 重点文件/子目录 | 运维实战说明 |
| :--- | :--- | :--- |
| **/var** | **(Variable) 经常变化的数据** | **磁盘爆满第一嫌疑人**。 |
| | **/var/log/** | **日志中心**。`messages`(系统), `secure`(安全/SSH), `nginx/` 等。 |
| | `/var/run/` | 存放 **PID 文件** (如 `nginx.pid`)。用于锁死进程防止重复启动。 |
| | `/var/lib/mysql` | MySQL 数据库默认存放路径 (建议生产环境改到独立大磁盘)。 |
| **/opt** | **(Optional) 第三方软件** | **大型软件/自研程序首选**。<br>教科书说用 `/usr/local`，但现在的运维规范更倾向于把手动部署的 Java/Go/Python 项目放在 `/opt` 或 `/app` 下，保持系统干净。 |
| **/usr** | **(User System Resources) 资源** | 类似 Windows 的 `C:\Windows` + `Program Files`。 |
| | **/usr/local/** | **编译安装目录**。如果你下载源码编译 Nginx/Redis，默认会装到这。 |
| | `/usr/bin/` | 系统预装命令 (ls, cp, mv)。 |
| **/home**| **普通用户主目录** | 比如用户 `dev` 的家在 `/home/dev`。<br>**⚠ 注意**：未授权 sudo 的用户只能在这里操作，出不去。 |
| **/root**| **管理员主目录** | Root 用户的家。注意它不在 `/home` 下。 |

#### 3. 虚拟与临时区 (内存映射与设备)

这里的“文件”大多不是存在硬盘上的，而是内存或硬件的映射。

| 目录 | 重点文件/子目录 | 运维实战说明 |
| :--- | :--- | :--- |
| **/tmp** | **临时文件** | **重启即清空！**<br>1. 任何用户都可读写。<br>2. 严禁把重要脚本或数据长期放这里。<br>3. 很多挖矿病毒喜欢藏在这里运行。 |
| **/proc**| **(Process) 内存/内核映射** | **不占硬盘空间**。这里全是系统运行时的状态。 |
| | `/proc/cpuinfo` | 查看 CPU 核数、型号。 |
| | `/proc/meminfo` | 查看内存详情。 |
| | `/proc/[数字ID]` | 查看某个进程的详细信息（启动路径、环境变量）。 |
| **/dev** | **(Device) 设备文件** | 一切硬件皆文件。 |
| | **/dev/null** | **黑洞**。`> /dev/null` 表示丢弃输出，谁也找不回来。 |
| | `/dev/zero` | **零发生器**。常用于 `dd` 命令生成测试大文件。 |
| | `/dev/sda` 或 `/dev/vda` | 系统第一块硬盘 (物理机/虚拟机)。 |

---


### 总结：运维各目录“潜规则”

*   **找配置**：先去 `/etc`，找不到再去 `/usr/local/软件名/conf`。
*   **找日志**：无脑去 `/var/log`。
*   **装软件**：
    *   `yum/apt` 装的 -> 分散在 `/usr/bin`, `/etc`。
    *   手动解压的/编译的 -> 统一扔到 `/opt` 或 `/usr/local`。
*   **磁盘满了**：
    *   先查 `/var/log` (日志爆炸)。
    *   再查 `/tmp` (垃圾文件没清)。
    *   最后查应用目录 `/opt` 或 `/home` (业务文件上传满了)。
