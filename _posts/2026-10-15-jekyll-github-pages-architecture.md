一个个人博客，最重要的事情是让写作变得轻松。

我希望这里没有太多喧闹的按钮。打开页面就能找到最近的文字，点开作品就能安静地读下去。

## 内容与页面各司其职

文章放在 Markdown 文件里，页面布局交给模板处理。修改标题和正文时，不需要改动网页代码。

本站的内容分为三个部分：博客文章、角色画集，以及短篇故事。它们各自拥有独立的网址，可以直接收藏或分享。

## 从一篇文字开始

一篇新文章只需要一个文件，文件名以日期开头，放入文章目录即可。文件开头记录标题、日期、分类和摘要，下面就是正文。

```yaml
---
title: 今天的云很好看
date: 2026-10-16 09:00:00 +0800
category: 日常随笔
description: 记下一次散步途中遇见的云。
---
```

## 把更新交给自动构建

当修改提交到 GitHub 仓库后，GitHub Actions 会生成静态页面，再发布到 GitHub Pages。发布完成后，首页的文章列表也会一起更新。

页面不需要数据库，也不需要一直运行的应用服务器。评论是独立的可选功能，需要配置后才会显示。

## 留白也是设计的一部分

页面选择本地样式和系统字体，减少等待。主题颜色、字号和阅读进度保存在读者自己的浏览器里。

把复杂的部分收起来，把空间留给文字。这是这座小岛想坚持的事情。
